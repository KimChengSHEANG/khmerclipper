What's new in 0.3.0

Released 24 October 2026. Measured on the same test images before and after; clean text reads exactly as it did in 0.2.1.

Faster up to 4×

Multi-line captures are read up to twice as fast on Mac, and about four times as fast on Windows and Linux.

Cluttered captures −26% errors

Text beside profile pictures, inside buttons and boxes, in tables or underlined links, or cut off by your selection now comes out with about a quarter fewer mistakes.

Retina captures full resolution

The Mac app captures at your screen's full pixel density, so small text is read more accurately.

Two-line captures fixed

Some captures of exactly two lines were read as one jumbled line. They're now split correctly.

Windows and Linux download the updated model (about 1.5 GB) once after upgrading. Release notes

How it works

A TrOCR model fine-tuned on over a million Khmer and English text lines, exported to run locally on each platform. The weights are on Hugging Face for your own fine-tuning.

Split into lines

Borders, underlines, pictures and cut-off lines are set aside first. Khmer subscripts of one line touch the marks of the next, so touching lines are cut at the line pitch and each piece is cropped to its ink.

Read each line

A ViT encoder and a decoder with one token per Khmer character, trained on public datasets plus about 750k synthetic lines rendered in dozens of Khmer and Latin fonts.

Pick the best reading

For lines with no Khmer, a confident Tesseract result wins, since it reads clean English UI text slightly better.

Install

Grab the latest build from GitHub Releases.

macOS

Open the .dmg and drag KhmerClipper to Applications. Grant Screen Recording when asked. Signed and notarized.

Windows

Run the -setup.exe. The build is unsigned, so SmartScreen asks once: More info → Run anyway.

Linux

sudo apt install ./khmerclipper_*.deb, or run the AppImage. The TrOCR model (~670 MB) downloads on first use.

Build from source

The macOS app is Swift; the Windows/Linux app is Python with PySide6 and ONNX Runtime.

git clone https://github.com/KimChengSHEANG/khmerclipper && cd khmerclipper

# macOS (Xcode 16+, brew install xcodegen)
cd apps/mac && make run

# Windows / Linux (Python 3.12)
cd apps/desktop && python3.12 -m venv .venv && .venv/bin/pip install -e '.[dev]'
.venv/bin/python tools/fetch_tessdata.py && .venv/bin/python -m khmerclipper

Training recipes, datasets and known issues are in the project guide.
