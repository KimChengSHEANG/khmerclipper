**KhmerClipper** reads Khmer (and English) text from anywhere on your screen and copies it, ready to paste.

## What's new

- **A new reading model (M3).** On KHOB, a public set of 1,862 real Khmer text lines, it makes about a fifth fewer mistakes than the previous model: a 2.6% character error rate, down from 3.3%. That is also below Chakkhu-OCR-Khmer, another open Khmer model, which scores 3.1% on the same lines.
- **Scans and busy images.** The new model was trained on many more scanned documents. On our hardest test images (busy backgrounds and noise) it makes 15% fewer mistakes on Windows and Linux, and 9% fewer on the Mac.
- **No more junk at the end of a line.** The model sometimes added a few stray characters after the real text. It now stops at the end of the line much more often.
- **Cut-off lines.** When a selection catches most of the line below, that partial line is now left out instead of being read as garbage.
- **Faster on Windows and Linux.** A whole capture takes about 14% less time than in 0.4.1.

Clean screenshots read about as well as before. On our 200-line test, 3 to 5 lines come out slightly differently, mostly a space or ្ដ written as ្ត (the two look the same in most fonts).

## Upgrading

Install over your current version; your preferences and history are kept.

- **Windows and Linux:** the app downloads the new reading model (about 700 MB) the first time you capture after upgrading.
- **Mac:** the model is inside the app, so there is nothing extra to download. The first capture after upgrading takes a few seconds longer while the Mac prepares the model.

## Download

Pick the file for your computer, under **Assets** below.

| Computer | File |
|---|---|
| Mac (macOS 15 or newer) | `KhmerClipper-0.4.2.dmg` |
| Windows 10 / 11 (64-bit) | `KhmerClipper-0.4.2-windows-x64-setup.exe` |
| Ubuntu / Debian (64-bit) | `khmerclipper_0.4.2_amd64.deb` |
| Other Linux (64-bit) | `KhmerClipper-0.4.2-x86_64.AppImage` |

## Install

### Mac

1. Open `KhmerClipper-0.4.2.dmg` and drag **KhmerClipper** onto **Applications**.
2. Open KhmerClipper from Applications. Its icon appears in the menu bar at the top of the screen.
3. When asked, allow **Screen Recording** (System Settings → Privacy & Security → Screen Recording), then reopen KhmerClipper.

### Windows

1. Double-click `KhmerClipper-0.4.2-windows-x64-setup.exe`.
2. If you see **"Windows protected your PC"**, click **More info**, then **Run anyway**. This appears because the app isn't signed with a paid Microsoft certificate yet. It is safe to install.
3. Follow the steps to finish installing. KhmerClipper starts in the system tray (bottom-right corner of the screen).

### Ubuntu / Debian

1. Download `khmerclipper_0.4.2_amd64.deb`, then run `sudo apt install ./khmerclipper_0.4.2_amd64.deb` in a terminal in the download folder.
2. Open **KhmerClipper** from the app menu. Its icon appears in the top bar.

### Other Linux

AppImages need FUSE 2. On Ubuntu 22.04 run `sudo apt install libfuse2`; on 24.04 and newer, `sudo apt install libfuse2t64`.

1. Make the file executable: right-click → Properties → Permissions → **Allow executing file as program**, or run `chmod +x KhmerClipper-0.4.2-x86_64.AppImage`.
2. Double-click it to start. On GNOME, the tray icon needs the **AppIndicator** extension (already on in Ubuntu).

## Use

1. Press **⌘⇧6** (Mac) or **Ctrl+Shift+2** (Windows / Linux), or choose **Capture Text** from the KhmerClipper icon.
2. Drag a box around the text. The text is copied. Paste it anywhere.

**Wayland (Linux):** add a keyboard shortcut in your desktop settings that runs `khmerclipper --capture` (.deb) or `/path/to/KhmerClipper-0.4.2-x86_64.AppImage --capture`.

---

Everything runs on your computer. Your screen captures are never uploaded.
