**KhmerClipper** reads Khmer (and English) text from anywhere on your screen and copies it, ready to paste.

## What's new

- **Text on busy backgrounds.** Text over photos, gradients and textures is now found line by line. On our busy test images, about a quarter fewer mistakes.
- **A better reading model.** The new model (M2) makes about 3% fewer mistakes on screen text and about 6% fewer on handwriting. Divider lines and broken characters no longer end up in your text.
- **Menus, tables and columns.** Rows with gaps keep all their items, side-by-side columns are read separately, and chat bubbles and photos of paper are split into lines properly.
- **Faster and smaller on Windows and Linux.** Screen captures are read about a quarter faster, and the model download is less than half the size.
- **Mac capture.** The crosshair now matches the system's screenshot tool, and the status popup says what happened.

## Upgrading

Install over your current version; your preferences and history are kept. On **Windows and Linux**, the app downloads its updated reading model (about 700 MB) once, the first time it opens. Until that finishes, switch to Tesseract in **Preferences → OCR Engine** if you need to capture right away.

## Download

Pick the file for your computer, under **Assets** below.

| Computer | File |
|---|---|
| Mac (macOS 15 or newer) | `KhmerClipper-0.4.0.dmg` |
| Windows 10 / 11 (64-bit) | `KhmerClipper-0.4.0-windows-x64-setup.exe` |
| Ubuntu / Debian (64-bit) | `khmerclipper_0.4.0_amd64.deb` |
| Other Linux (64-bit) | `KhmerClipper-0.4.0-x86_64.AppImage` |

## Install

### Mac

1. Open `KhmerClipper-0.4.0.dmg` and drag **KhmerClipper** onto **Applications**.
2. Open KhmerClipper from Applications. Its icon appears in the menu bar at the top of the screen.
3. When asked, allow **Screen Recording** (System Settings → Privacy & Security → Screen Recording), then reopen KhmerClipper.

### Windows

1. Double-click `KhmerClipper-0.4.0-windows-x64-setup.exe`.
2. If you see **"Windows protected your PC"**, click **More info**, then **Run anyway**. This appears because the app isn't signed with a paid Microsoft certificate yet. It is safe to install.
3. Follow the steps to finish installing. KhmerClipper starts in the system tray (bottom-right corner of the screen).

### Ubuntu / Debian

1. Download `khmerclipper_0.4.0_amd64.deb`, then run `sudo apt install ./khmerclipper_0.4.0_amd64.deb` in a terminal in the download folder.
2. Open **KhmerClipper** from the app menu. Its icon appears in the top bar.

### Other Linux

AppImages need FUSE 2. On Ubuntu 22.04 run `sudo apt install libfuse2`; on 24.04 and newer, `sudo apt install libfuse2t64`.

1. Make the file executable: right-click → Properties → Permissions → **Allow executing file as program**, or run `chmod +x KhmerClipper-0.4.0-x86_64.AppImage`.
2. Double-click it to start. On GNOME, the tray icon needs the **AppIndicator** extension (already on in Ubuntu).

## Use

1. Press **⌘⇧6** (Mac) or **Ctrl+Shift+2** (Windows / Linux), or choose **Capture Text** from the KhmerClipper icon.
2. Drag a box around the text. The text is copied. Paste it anywhere.

**Wayland (Linux):** add a keyboard shortcut in your desktop settings that runs `khmerclipper --capture` (.deb) or `/path/to/KhmerClipper-0.4.0-x86_64.AppImage --capture`.

---

Everything runs on your computer. Your screen captures are never uploaded.
